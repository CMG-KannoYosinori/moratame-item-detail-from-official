# Git commit

ユーザーが `commit` と入力したら、確認せずにコミットを作成する。

## 粒度

変更を意味ごとに分割してコミットする。無関係な変更をまとめない。

例: レイアウト / 文言 / 画像差し替え / CSS余白 / 未使用ファイル削除 は別コミット。

## メッセージ

- 先頭に gitmoji（絵文字そのもの。`:fire:` のような shortcode は使わない）
- 続けて日本語の件名。なぜの説明を1行で書く
- 件名は1行。自明でないときだけ本文を足す
- 絵文字なしのコミットメッセージは作らない

```
🔥 未使用の画像ファイルを削除
💄 カード背景に合わせて余白を調整
✨ おふろBOXをPC2列レイアウトにする
```

## よく使う gitmoji

| 絵文字 | 用途 |
|--------|------|
| 🎉 | 初回コミット / プロジェクト開始 |
| ✨ | 新機能 |
| 🐛 | バグ修正 |
| 🔥 | コードやファイルの削除 |
| 💄 | UI / スタイル更新 |
| 📝 | ドキュメント |
| 🔧 | 設定ファイル |
| 🙈 | .gitignore 関連 |
| ♻️ | リファクタリング |
| 🚚 | ファイル・ディレクトリの移動 / リネーム |
| 🍱 | アセット追加・更新 |
| ✅ | テスト追加・更新 |
| 🚀 | デプロイ関連 |
