# 文字化けしやすい記号は実体参照にする

HTML のテキストと属性値（`alt`、`title` など）では、環境によって文字化けしやすい記号を生の文字で書かない。数値文字参照（`&#番号;`）にする。`&reg;` のような名前付き実体参照は使わない。

ひらがな・カタカナ・漢字、および JIS にある句読点（`、。！？（）「」・`）はそのまま書く。

## よく出る記号

| 記号 | 実体参照 |
| --- | --- |
| ® | `&#174;` |
| © | `&#169;` |
| ™ | `&#8482;` |
| × | `&#215;` |
| ÷ | `&#247;` |
| ℃ | `&#8451;` |
| ～（全角チルダ） | `&#65374;` |
| 〜（波ダッシュ） | `&#12316;` |
| −（マイナス） | `&#8722;` |
| —（ダッシュ） | `&#8212;` |
| … | `&#8230;` |
| ① | `&#9312;` |

```html
<!-- 悪い -->
alt="スターバックス®"
400mg×30粒（0.02〜0.06g）

<!-- 良い -->
alt="スターバックス&#174;"
400mg&#215;30粒（0.02&#12316;0.06g）
```

CSS の `content` では HTML の実体参照は展開されない。記号が必要なら Unicode エスケープにする（例: 全角チルダは `\ff5e`）。
