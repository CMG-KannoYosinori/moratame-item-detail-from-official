# 簡単マニュアル（使う人向け）

案件を1つ作るときの操作の順番です。くわしい説明は [manual.md](manual.md) にあります。

Google Drive の場所: `共有ドライブ/design2/MOD_design/モラタメ商品概要LP_AIエージェント制作`

## 1. 作業フォルダを作る

1. `01_エージェント最新版` の `moratame-lp-年月日時分.zip` を、`02_案件ごとの作業フォルダ` にコピーする。
2. コピーした zip を解凍する（Mac はダブルクリック、Windows は右クリック →「すべて展開」）。zip は消してよい。
3. できたフォルダの名前を **`案件番号_商品名`** に変える（例: `99902_牛乳石鹸AKA`）。
   - 空白と記号は使わない。商品名に `_` は入れない。案件番号が決まっていなければ `未定`。
4. フォルダを右クリック →「オフラインで使用可能にする」。

> 1つのフォルダで扱う案件は1つです。同じフォルダを2人で同時に開かないでください。

## 2. Claude で始める

1. Figma で、この案件用の新しいファイルを作っておく（URL を聞かれます）。
2. Claude のアプリを開き、**Code** に切り替えて、作業フォルダに 1 のフォルダを選ぶ。
3. 入力欄に `/moratame-lp` と入力する。
4. 質問に答える（Figma の URL、案件番号、ブランドサイトの URL、対象商品、配送の条件）。分からないものは「分からない」でよい。

## 3. 工程ごとにすること

| 工程 | Claude がすること | あなたがすること | 次へ進むときの言葉 |
|---|---|---|---|
| 1 内容の整理 | ブランドサイトを読む | 待つ。読めないと言われたら、ページを保存したファイルかスクリーンショットを渡す | — |
| 2 ワイヤーフレーム | 画面の URL（`http://127.0.0.1:8000/…`）を教える | ブラウザで開き、使うブロックにチェック、商品の扱いを選んで「blocks.md に保存」 | 「保存しました」→ 直しがあれば言葉で頼む →「これで進めて」 |
| 3 デザイン | Figma にカンプを作る | Figma で見て、直してほしいところを会話か Figma のコメントで伝える | 「承認します」 |
| 4・5 HTML | HTML を作り、スクリーンショットを見せる | 気になるところを伝える | 「OK」 |

公開の作業（画像のアップロード、CMS への貼り付け）は人が行います。Claude がやることの一覧を書いてくれます。

## 4. 修正が来たら（何回でも）

1. 同じ作業フォルダを Claude で開く。
2. メーカーからの依頼をそのまま渡す（メールの文を貼る、PDF・画像を渡す、「B05 の見出しを〇〇に」と書く、など）。
3. Claude が一覧にして直すので、確かめて「OK」と伝える。

前の版に戻したいときは「前の版に戻して」と頼めます。

## 5. 途中でやめる・再開する

- いつやめてもよい。再開は、同じフォルダを開いて `/moratame-lp` か「進み具合を教えて」。
- ワイヤーフレームの画面が開かなくなったら「ワイヤーフレームの画面を開けるようにして」。
- フォルダの名前を変えるときは、Claude のアプリを閉じてから変える。

## 6. フィードバックを送る

使っていて困ったこと、分かりにくかったこと、こうしてほしいことがあれば、Claude にこう言います。

```
フィードバック: ワイヤーフレームの保存ボタンがどこにあるか分からなかった
```

作業フォルダの `feedback/` にメモが残り、管理者が集めて直します。送る操作は要りません。小さなことでもかまいません。

## 7. 案件が終わったら

作業フォルダはそのまま `02_案件ごとの作業フォルダ` に残します（移さない・消さない）。後から修正が来たら、同じフォルダで続けます。
