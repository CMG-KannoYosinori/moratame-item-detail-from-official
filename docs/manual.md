# 使い方マニュアル

ブランドサイトをもとに、モラタメの商品詳細ページ（商品概要の部分）を作るための手順です。Claude に話しかけながら進めます。git や HTML の知識がなくても使えるように書いています。作業用のフォルダは、管理者が Google Drive に置く最新の版から、案件ごとに作ります。操作の順番だけを見たいときは [quickstart.md](quickstart.md)（簡単マニュアル）。

## 1. できること

商品のブランドサイトの URL を伝えると、Claude が次の順に作業します。あなたがすることは、**質問に答えることと、見せられたものを確認すること**です。

| 工程 | Claude がすること | あなたがすること |
|---|---|---|
| 0 聞き取り | 必要なことを質問する | 質問に答える |
| 1 内容の整理 | ブランドサイトを読んで、文言・商品・画像を整理する | 待つ |
| 2 ワイヤーフレーム | LP の部品（ブロック）の候補を並べた画面を用意する | 画面で、使うブロックと商品を選んで保存する |
| 3 デザイン | Figma に PC と スマホ のデザインを作る | Figma で確認して、直してほしいところを伝える。よければ承認する |
| 4・5 HTML | デザインどおりに HTML を作って確認する | 最終確認をする |
| 6 修正 | メーカーからの修正の依頼を反映する（何回でも） | 依頼を渡して、直したものを確認する |

## 2. 準備（最初の1回だけ）

Mac でも Windows でも使えます。

| 入れるもの | Mac | Windows |
|---|---|---|
| Claude のアプリ | 入れて、Claude のアカウントでログイン | 同じ |
| Figma | アカウントを用意し、Claude のアカウントに Figma をつなぐ（claude.ai の設定のコネクタから） | 同じ |
| Google Drive for desktop | 入れて、会社の Google アカウントでログイン。Finder の左に「Google Drive」が出る | 入れて、会社の Google アカウントでログイン。エクスプローラーに「Google Drive」（G: ドライブなど）が出る |
| Python | 最初から入っている。Claude が初めてコマンドを使うときに「コマンドライン・デベロッパ・ツールをインストールしますか」と聞かれたら「インストール」を押す | [python.org](https://www.python.org/downloads/) から入れる。インストールの最初の画面で **「Add python.exe to PATH」にチェックを入れる** |
| Git for Windows | 要らない | Claude のアプリの Code（Claude Code）がコマンドを動かすのに使うので入れる（[gitforwindows.org](https://gitforwindows.org/)。設定は最初のままでよい）。git の操作をするわけではありません |
| ブラウザ | Google Chrome があれば使う（なくてもよい） | Chrome がなくても、最初から入っている Microsoft Edge を使う |

入れ終わったら、Google Drive の `共有ドライブ/design2/MOD_design/モラタメ商品概要LP_AIエージェント制作` が開けることを確かめます。

git や GitHub の操作はしません。

### Google Drive のフォルダ

```
共有ドライブ/design2/MOD_design/モラタメ商品概要LP_AIエージェント制作
├── 01_エージェント最新版/              管理者が最新の版（moratame-lp-年月日時分.zip）を置く
└── 02_案件ごとの作業フォルダ/          案件ごとの作業フォルダ（1案件1フォルダ）
    ├── 99902_牛乳石鹸AKA/
    └── 99903_キリングッドエール/
```

- **1つの案件は1人が担当します。** 同じ案件フォルダを、2人で（または2台の PC で）同時に開かないでください。Google Drive がファイルの複製を作り、どれが正しいか分からなくなります。
- 案件フォルダは、作業を始めたら「オフラインで使用可能」にしておきます（Finder・エクスプローラーでフォルダを右クリック →「オフラインで使用可能にする」）。Claude がたくさんのファイルを読むときに速くなります。
- Windows では、ファイルの場所（パス）が長すぎると扱えないことがあります。案件フォルダの名前の商品名は短くしてください。

## 3. 始め方（案件ごと）

案件を始めるたびに、**その時点で最新の版**から作業フォルダを作ります。

1. Finder（Windows ではエクスプローラー）で `共有ドライブ/design2/MOD_design/モラタメ商品概要LP_AIエージェント制作` を開き、`01_エージェント最新版` にある `moratame-lp-年月日時分.zip` を、`02_案件ごとの作業フォルダ` にコピーします。
2. `02_案件ごとの作業フォルダ` の中で zip を解凍します（Mac はダブルクリック。Windows は右クリック →「すべて展開」）。`moratame-lp-年月日時分` というフォルダができます。コピーした zip は消してかまいません。
3. できたフォルダの名前を、**`案件番号_商品名`**（例: `99902_牛乳石鹸AKA`）に変えます。決まりは下の「案件フォルダの名前の決まり」を見てください。
4. フォルダを「オフラインで使用可能」にします。
5. Claude のアプリを開き、**Code** に切り替えて、作業するフォルダにこの案件フォルダを選びます。
6. 入力欄に次のように入力します。

   ```
   /moratame-lp
   ```

   「牛乳石鹸 AKA の LP を作りたい」のように、ふつうの言葉で頼んでもかまいません。

7. Claude が質問するので、答えて進めます。

**1つの作業フォルダでは1つの案件だけを扱います。** 別の案件は、また 1 から新しいフォルダを作ってください。

**Figma のファイルは、案件ごとに自分で新しく作っておき**、その URL を伝えます（編集できる権限が必要です）。

### 案件フォルダの名前の決まり

形: **`案件番号_商品名`**

| 部分 | 決まり | 例 |
|---|---|---|
| 案件番号 | モラタメの案件番号（`project_id`）を半角英数字で。決まっていなければ `未定` | `15403`、`e6cf4`、`未定` |
| `_` | 案件番号と商品名の間に1つだけ | |
| 商品名 | ブランド名と商品名を短く（全体で20文字くらいまで）。日本語・半角英数字・`-`（ハイフン）だけを使う | `牛乳石鹸AKA`、`TheFace泡洗顔料`、`ビオレ-TheFace` |

**使わないもの**

- 空白（半角・全角とも）。英語の名前は `The Face` ではなく `TheFace` のように詰める
- 商品名の中の `_`（案件番号との区切りと見分けがつかなくなるため）
- 記号: `/ \ : * ? " < > | # % & ' ( ) [ ] { } ! @ ~ ^ + = , ;` など。®・™・☆・絵文字なども使わない
- 名前の最後の `.`（点）

| よい例 | よくない例 | 理由 |
|---|---|---|
| `00001_TheFace泡洗顔料` | `00001_The Face 泡洗顔料` | 空白がある |
| `99903_キリングッドエール` | `99903_キリン/グッドエール` | `/` は使えない |
| `未定_牛乳石鹸AKA` | `_牛乳石鹸AKA` | 案件番号がない（決まっていなければ `未定`） |
| `15403_ビオレ-TheFace` | `15403_ビオレ_The_Face` | 商品名の中に `_` がある |

**名前を変えるとき**（案件番号が決まった、決まりと違っていた など）は、**Claude のアプリを閉じてから** Finder・エクスプローラーで変えます。開いたまま変えると、Claude が作業中の場所を見失います。変えたら、新しい名前のフォルダを開き直して「進み具合を教えて」と聞きます。

Claude は、案件を始めるときにフォルダの名前を確かめ、決まりと違っていれば直した名前を提案します。

## 4. 各工程ですること

### 工程0: 質問に答える

Claude が次のことを聞きます。分からないものは「分からない」と答えてかまいません。

- Figma ファイルの URL（毎回聞かれます）
- 案件番号（決まっていなければ、練習用の番号を提案してくれます）
- ブランドサイトの URL
- 対象商品（モラタメで今回試せる商品）と個数。分からなければ、工程2で選べます
- 配送の条件（通常 / 沖縄以外 / 冷凍便 / 冷蔵便。選択肢から選びます）

### 工程1: 待つ

Claude がブランドサイトを読みます。サイトによっては自動で読めないことがあります。そのときは「ブラウザで保存した HTML かスクリーンショットをください」と言われるので、用意して渡してください。

終わると、見つかった商品の一覧と、載せるときに注意が必要な表現（体への効果をうたう言葉など）を教えてくれます。

### 工程2: 画面でブロックと商品を選ぶ

Claude が `http://127.0.0.1:8000/…/wireframe.html` のような URL を教えてくれるので、ブラウザで開きます。左に PC、右にスマホの見え方が並んでいます。

| やりたいこと | 操作 |
|---|---|
| ブロックを使う / 使わない | 各ブロックの左上のチェックを付ける / 外す |
| 並び順を変える | ブロックの左上の **↑ ↓** |
| 文言の直しや指示を書く | ブロックの左上の **メモ** を押して書く |
| 商品の扱いを決める | 商品カードの右上で「対象（今回試せる）/ 紹介のみ / 載せない」を選ぶ |
| 使わないブロックを隠す | 上の「使わないブロックも薄く表示する」のチェックを外す |
| 保存する | 上の **「blocks.md に保存」**（または ⌘+S） |

- 「必須」の赤いブロックを外すときは、メモに理由を書かないと保存できません。
- 対象の商品が1つもないと保存できません。
- 保存したら、Claude に「保存しました」と伝えてください。抜けや重なり、表現で気になる点を教えてくれます。
- 追加や修正は、ふつうの言葉で頼めます（例:「B05 の見出しを短くして」「コラムの○○もブロックにして」）。Claude が直したら、ブラウザを再読み込みします。
- **Claude に直してもらう前に、画面で選んだ内容を保存してください。** 保存していない選択は、再読み込みで消えます。
- よければ「これで進めて」と伝えます。

### 工程3: Figma でデザインを確認する

Claude が Figma の URL を教えてくれます。「カンプ」ページに、PC とスマホのデザインと、黄色いメモ（仮の値や確認してほしいこと）が並んでいます。

- 直してほしいところは、**会話で伝えるか、Figma のコメントで**その場所に書きます。コメントで書いたときは「Figma にコメントしました」と伝えてください。
- メモの「要確認」の項目には、載せてよいかどうかを答えてください。
- よければ「承認します」と伝えます。

### 工程4・5: HTML を確認する

Claude が HTML を作り、PC とスマホのスクリーンショットで確認結果を見せてくれます。気になるところを伝え、よければ「OK」と伝えます。

公開の作業（画像などのアップロード、CMS への貼り付け）は人が行います。Claude がやることの一覧を書いてくれます。

### 工程6: 修正が来たら（何回でも）

HTML を作った後に、メーカーから修正の依頼（戻し）が来ることがよくあります。そのときは、依頼をそのまま Claude に渡してください。

- 渡し方は何でもかまいません。メールの文章を貼り付ける、赤字を入れた PDF や画像を渡す、「B05 の見出しを〇〇に変えて」と書く、など。
- Claude が依頼を1件ずつに分けて一覧にし、ワイヤーフレームの記録・デザイン（Figma）・HTML をそろえて直します。最初からやり直すことはありません。
- 新しいブロックを足す、見た目を大きく変えるといった依頼は、先に Figma のデザインを見せてくれます。よければ「OK」と伝えると、HTML を直します。
- 体への効果をうたう言葉など、載せてよいか確認が必要な依頼は、Claude が確認を求めてきます。
- 届いたファイルは `projects/{案件番号}/revisions/round-{回の番号}/request/` に入れてから、「第2回の修正です」のように伝えてください（フォルダは Claude に作ってもらえます）。迷ったら PDF にしてもらうのが確実です。
- 直す前の版は残っています。「前の版に戻して」と頼めば戻せます。
- 依頼と対応の記録は `projects/{案件番号}/changes.md` に残ります。メーカーへの返信用のまとめが必要なら、「修正内容のまとめを作って」と頼んでください。
- くわしい流れ、受け取れるファイルの形式、フォルダの使い方は [revision-flow.md](revision-flow.md) にあります。

## 5. 途中でやめる・続きから再開する

- いつやめても大丈夫です。進み具合は [progress.md](../projects/progress.md) に記録されています。
- 再開するときは、`/moratame-lp` と入力するか、「○○の続きをして」と頼みます。
- 工程2の画面は、Claude を閉じると開けなくなります。再開したら「ワイヤーフレームの画面を開けるようにして」と頼んでください。

## 6. 案件が終わったら

- 作業フォルダは Google Drive の `02_案件ごとの作業フォルダ` にあるので、そのままで共有・保存されます。移したり消したりしないでください（修正が後から来ることがあります）。
- 使っていてつまずいたこと、分かりにくかったことがあれば、Claude に「フィードバック: 〇〇」と言ってください（下の 8）。

## 7. 版について

- 使っている版は、作業フォルダの `VERSION` というファイルに書いてあります。
- 案件の途中で新しい版が出ても、その案件は**始めたときの版のまま**続けてかまいません。後から修正が来たときも、同じフォルダで対応します。
- 新しい版の機能を使って続けたいときだけ、次のようにします。
  1. `01_エージェント最新版` の最新の zip を `02_案件ごとの作業フォルダ` にコピーして解凍し、新しいフォルダを作ります（名前は始め方の 3 と同じ決まり）。
  2. 古いフォルダの `projects` と `feedback` を、新しいフォルダの中にドラッグします（「置き換えますか」と聞かれたら「置き換える」）。
  3. 新しいフォルダを Claude で開き、「進み具合を教えて」と聞いて、案件が見えることを確かめます。
  4. 確かめたら、古いフォルダの名前の最後に「_旧」を付けておきます（すぐには消さない）。

## 8. 困ったとき・改善してほしいとき

使っていて困ったこと、分かりにくかったこと、こうしてほしいことがあれば、Claude に「フィードバック: 〇〇」と言ってください。`feedback/` にメモが残り、管理者がまとめて直します。くわしくは [feedback-flow.md](feedback-flow.md)。

### よくある困りごと

| こんなとき | どうする |
|---|---|
| ワイヤーフレームに「blocks.md に保存」ボタンがない | Live Server（`:5500`）などで開いています。Claude が教えた `:8000` の URL で開き直してください |
| ワイヤーフレームの画面が開かない | Claude に「ワイヤーフレームの画面を開けるようにして」と頼んでください |
| 保存すると「書き換えられています」と出る | 画面を開いた後に Claude がファイルを直しています。ブラウザを再読み込みして、選び直してから保存してください |
| Figma が使えないと言われる | claude.ai の設定で Figma がつながっているか確かめてください |
| 「このコマンドを実行してよいか」と何度も聞かれる | 内容を見て許可してください。多すぎるときは管理者に伝えてください（あらかじめ許可しておく設定ができます） |
| ブランドサイトが読めないと言われる | ブラウザでページを保存（⌘+S）したファイルか、スクリーンショットを渡してください |
| どこまで進んだか分からない | 「進み具合を教えて」と聞いてください |
| 新しい版にしたら案件が消えた | 古いフォルダの `projects` を移し忘れています。「7. 版について」の 2 をやり直してください |
| ファイル名の最後に「(1)」が付いたファイルができた | 同じ案件フォルダを2か所で同時に開いた可能性があります。どちらが正しいか、Claude に「(1) の付いたファイルと元のファイルを比べて」と頼んで確かめてください |
| Claude の動きが遅い | 案件フォルダを「オフラインで使用可能」にしてください |
| Mac から「コマンドライン・デベロッパ・ツール」のインストールを求められた | 「インストール」を押して、終わったら Claude に「続けて」と伝えてください |
| Windows で「Python が見つからない」と言われた | Python を入れ直し、最初の画面で「Add python.exe to PATH」にチェックを入れてください。入れたら Claude のアプリを開き直します |
| Windows で、Claude がコマンドを動かせないと言われた | Git for Windows を入れて、Claude のアプリを開き直してください |
| Windows で、ワイヤーフレームの画面を開くときに「アクセスを許可しますか」と聞かれた | 自分の PC の中だけで使うものなので、「許可」を選んでかまいません |

| 案件ごとの作業 | `projects/{案件番号}/` |

| 選んだブロックと商品 | `projects/{案件番号}/wireframe/blocks.md` |

| くわしい決まり | [docs/requirements.md](requirements.md) |
