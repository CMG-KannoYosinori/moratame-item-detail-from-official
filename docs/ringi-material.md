## 1. 前提: 何をするか

モラタメの商品詳細ページ（`tamesu.php?project_id=xxx`）の「商品概要」は、メーカーのブランドサイトをもとに、社内でデザインと HTML を作っている。この作業を、AI エージェント（Claude）に任せる。

| 工程 | Claude がすること | 担当者がすること |
|---|---|---|
| 内容の整理 | ブランドサイトを読み、文言・商品・画像・動画・注意が必要な表現を一覧にする | 案件番号やURLを答える |
| 構成 | ページの構成案（ブロック）を多めに並べた画面を作る | 画面で、使うブロックを選ぶ |
| デザイン | Figma に PC 用・スマホ用のデザインを作る | Figma で見て、直すところを伝える。承認する |
| HTML | 社内のテンプレートから HTML を作り、画像を圧縮し、PC・スマホの表示を確かめる | 確認する |
| 修正 | メーカーからの戻しを1件ずつ反映し、記録を残す | 戻しを渡す。確認する |
| 公開 | 公開の前にやることを一覧にする | 画像のアップロードと CMS への入稿（誤公開を防ぐため人がやる） |

仕組み（手順書・テンプレート・確認の手順）は作成済みで、練習用の1件（ヤガイ「サポートミート」）で、ブランドサイトの読み取りから HTML、メーカーの修正対応まで通しで動くことを確かめた（2026-11-24）。

## 3. なぜこれが良いのか

### 3.1 仕事がどう良くなるか

- **時間が減る:** 1件 約19時間かかっている作業が、人の時間で 約4時間になる見込み【仮】（くわしくは 5）。
- **作れる人が増える:** HTML や Figma に慣れていない担当者でも、質問に答えて確認するだけで作れる。今は作れる人が限られている。
- **出来がそろう:** 社内のテンプレートとコーディングの決まり、PC・スマホの確認、画像の圧縮（1枚 300KB 目安）を、毎回同じ手順で行う。
- **抜けが減る:** ブランドサイトの商品をすべて一覧にし、動画も拾う。注意が必要な表現（薬機法・景品表示法）は言い換えずに控え、人に確認を求める。
- **修正の記録が残る:** メーカーからの戻しごとに、受け取ったファイル・直す前の版・対応の内容が残る。言った・言わないを防ぎ、元にも戻せる。
- **担当が替わっても続けられる:** 進み具合が案件ごとに記録されるので、途中から別の人が引き継げる。

### 3.2 この仕組みを選ぶ理由

1. **すでに動く:** 手順書とテンプレートの仕組みが作成済みで、練習の1件で通しで動いた。追加の開発費がかからない。
2. **デザインまで作れる:** Figma の公式の連携で、Claude が Figma にデザインを直接作る。デザインを承認してから HTML にする、今の確認の流れをそのまま残せる。
3. **人による差が出にくい:** 手順を Claude の「スキル」として決めてあるので、誰がやっても同じ順番・同じ決まりで進む。
4. **業務用の規約:** Team プランは業務向けの規約で、入力した内容は初期設定で AI の学習に使われない。管理者が席をまとめて管理できる。
5. **小さく始められる:** 2人から、月払いで始められる。席の種類も1人ずつ変えられる。

## 4. 他のやり方との比較

| やり方 | 費用 | 1件の人の時間 | 良いところ | 問題 |
|---|---|---|---|---|
| **A. 本提案**（Claude と社内用の手順書・Figma の連携） | 1人 月 約5,600円 | 約4時間【仮】 | 人は確認だけ。Figma のデザインと HTML まで作る。手順が決まっているので人による差が小さい | 試行で使える量と出来を確かめる必要がある |
| B. 今のやり方（社内の手作業） | 追加なし | 約19時間【仮】 | 慣れている | 時間がかかる。作れる人が限られる |
| C. 制作会社に外注 | 1件 数万円〜【要見積】 | 指示・確認・修正のやりとりが残る（数時間） | 社内の手が空く | 件数に比例して費用が増える。修正のたびに往復の日数がかかる |
| D. ブラウザの AI チャットを使う（ChatGPT・Claude など） | 1人 月 約3,000円 | 10時間以上【仮】 | 文章の下書きは速い | Figma やテンプレート・ファイルを直接扱えないので、組み立てと貼り付けは人。やり方が人によってばらつく |
| E. ほかの AI 開発ツール（Cursor、OpenAI Codex など） | A と同じくらい | A に近い | できることは近い | 今の手順書（Claude の形式）を作り直す必要がある。Figma との連携も確かめ直しになる |
| F. ノーコードのLP作成サービス（STUDIO など） | 月数千円〜 | — | 画面で組める | モラタメは CMS に HTML を貼る形でテンプレートも決まっているので、使えない |

**比べた結果:** 人の時間が一番少ないのは A と E。そのうち、作成済みの手順書とテンプレートをそのまま使え、すぐに始められるのは A。外注（C）と比べると、件数が増えても費用が増えない。

## 5. 削減の見込み

### 5.1 1件あたりの作業時間

| 工程 | 今（手作業）【仮】 | 導入後（人がかける時間）【仮】 |
|---|---|---|
| 内容の整理（ブランドサイトを読み、文言・画像・注意表現を集める） | 2.0時間 | 0.3時間 |
| 構成を考える | 1.5時間 | 0.5時間 |
| デザイン（PC・スマホ） | 6.0時間 | 1.0時間 |
| HTML・CSS・画像の書き出しと圧縮 | 5.0時間 | 0.5時間 |
| 表示と表現の確認 | 1.0時間 | 0.7時間（法令に関わる表現の確認は人に残す） |
| 公開の作業（アップロード・入稿） | 0.5時間 | 0.5時間（変わらない） |
| メーカーの修正 2回（1回 1.5時間 → 0.4時間） | 3.0時間 | 0.8時間 |
| **合計** | **19.0時間** | **4.3時間（約77%減）** |

この表どおりにいかないことも考え、**削減できる時間を半分（1件 約7.4時間）と見て**、以下を計算する。

### 5.2 月の効果（保守的に見た場合）

人の時間の単価を 3,000円/時間【仮】とすると、**1件で 約22,000円分の時間が減る**（約7.4時間 × 3,000円）。

ここから、毎月かかる次の2つを引いたものを、月の効果とする。

- 管理者が仕組みの手入れにかける時間: 月8時間【仮】＝ 約24,000円
- 契約費: 1人 月 約5,600円 × 人数

1か月に作るLPは **30件**（全員の合計）とする。下の表は、**5人で使う場合**の例（契約費 月 約28,000円）。

| 1か月に作るLPの数 | 減る時間 | 金額にすると | 手入れと契約費を引く | 月の効果 |
|---|---|---|---|---|
| 30件 | 約221時間 | 約662,000円 | −約52,000円 | **約610,000円**（年 約732万円） |

- 使う人が1人増えるごとに、月の効果は 約5,600円ずつ減る（例: 10人なら 月 約58万円、20人でも 月 約53万円）。

## 6. 参考: リスクと対策

| リスク | 対策 |
|---|---|
| AI がまちがえる（文言・数値・表示） | 構成・デザイン・HTML のそれぞれで人が確認するまで先に進まない作りにしてある。公開と入稿は人がやる |
| 薬機法・景品表示法に触れる表現 | Claude は表現を言い換えない決まり。体への働きをうたう表現は人に確認を求める。最後は人が確認する |
| ブランドサイトの画像の使用許可 | 今までどおり、クライアントに確認する |
| 使える量の上限（Claude、Figma） | Claude は、仕組みの開発と練習の1件を、標準席より使える量の少ない Pro プランで進められた。足りない人が出たら、その人だけプレミアム席（月 約15,500円、使える量は標準席の5倍）に上げる（1人 月 約12,400円増える）。Figma の連携は1日200回まで（Professional の場合）。試行中に1件あたりの回数を測る |
| 料金の変更 | 試行の結果と合わせて、本導入の前に見直す |
| Windows の PC で未確認 | 試行の最初の1件で確かめる。手順は Mac・Windows の両方に対応させてある |
| 情報の扱い | 扱うのはブランドサイトの公開情報とメーカーからの戻し。作業ファイルは担当者の PC と社内の Google Drive に置く |

## 7. 参考: 試行の進め方（3か月）

| 時期 | すること | 人数 | 判断の材料 |
|---|---|---|---|
| 1か月目 | Claude と Figma を契約。担当者1人が、管理者と一緒に実案件を作る | 2人（管理者・担当者1人） | 1件あたりの人の時間、つまずいたところ |
