## 起きたこと

「Youtube 埋め込みのブロックが抜けているようです。」

ワイヤーフレームのブロック候補に、YouTube の埋め込み（テンプレート部品 `-youtube`）が1つも出ていなかった。ブランドサイトのトップには動画が埋め込まれていた。

## してほしいこと

ブランドサイトに動画があるときは、YouTube のブロックを候補に出してほしい。

## Claude の補足

- 原因: 工程1（`brand-content`）で HTML から見出し・本文・画像を抜き出したとき、`iframe` を見ていなかった。スキルの「読み取り方」も `img` と `picture` の `source` しか挙げておらず、`iframe`（YouTube の `youtube.com/embed/…`）や動画には触れていない。
- 今回トップにあったもの: `youtube.com/embed/cmBOhx7O9cE`（KV のすぐ下。自動再生・ミュート・ループ）。
- ブランドの CM ページ（`/biore/cm/`）にも商品の CM があったが、トップのメニューにあるだけのページなので読まなかった。
- 直し方の案:
  - `brand-content` の「読み取り方」に「`iframe`・`video` を拾う（YouTube の ID を控え、oEmbed で題名を確かめる）」を足す。
  - 「CM・動画のページがあれば読む」を足す。
  - content.md の書き方に「動画」の節を足す。`lp-wireframe` で、動画があれば `-youtube` のブロックを候補に出す。
