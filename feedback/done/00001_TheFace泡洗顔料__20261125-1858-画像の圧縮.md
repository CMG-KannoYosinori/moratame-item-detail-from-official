## Claude の補足

- 原因: `moratame-html` の「2. 画像を用意する」に、大きさ（1276px 幅が基準）は書いてあるが、**ファイルの重さと圧縮の決まりがない**。ブランドサイトの元画像（Scene7 の `?fmt=png-alpha&scl=1` で原寸を取った PNG。1500px 前後）をそのまま置いた。
- 手元に、Mac・Windows の両方で使える圧縮の道具がない。Pillow は入っておらず、`sips` は Mac だけなので CLAUDE.md の決まりで使えない。`tools/` にも圧縮のスクリプトがない。
- 直し方の案（推測を含む）:
  - `tools/` に圧縮のスクリプトを足す。依存なしで縮小・再圧縮するのは難しいので、次のどれかを選ぶ必要がある。
    - Pillow を必須にする（`pip install Pillow`。Windows でも入る）。1276px 幅への縮小、写真は JPEG（品質80前後）、透過のある画像は PNG の減色か WebP。
    - headless Chrome（`tools/screenshot.py` で既に使っている）の canvas で縮小して書き出す。追加の導入は要らないが、PNG の減色はできない。
    - 人が TinyPNG・Squoosh などのウェブの道具で圧縮する手順を、manual.md と moratame-html の「終わったら」に書く。
  - `moratame-html` に目安を書く（例: 1枚 300KB 以下、ページ合計 3MB 以下。数値は要相談）。工程5の確認に「画像の合計の大きさ」を足す。
  - ブランドサイトから取るとき、Scene7 なら `?wid=1276&fmt=jpg&qlt=80` のように、配信側で縮小・形式変換したものを取る手もある（透過が要らない画像に限る）。
